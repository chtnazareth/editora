# [Nome do Livro]

Estrutura de escrita estilo Scrivener, montada para o Obsidian.

> Esta pasta nasceu do molde `_Template Livro`. Veja **COMO USAR — Template** para
> o passo a passo de começar um livro novo. Troque este título pelo nome do livro.

## Mapa das pastas
- **01 — Bíblia do Mundo** — decisões, premissa, tom, regras do projeto (a "fonte da verdade").
- **02 — Personagens** — fichas. Promova nomes do *Elenco a Definir* para notas próprias.
- **03 — Lugares** — cenários.
- **04 — Mundo** — sistema, regras e cronologia (worldbuilding).
- **05 — Manuscrito** — o livro em si: `Ato 1/2/3`, cada um com seus capítulos.
- **06 — Notas e Pesquisa** — captura solta e referências.
- **Templates** — modelos para criar novos capítulos/cenas/personagens.
- **Painel.base / Painel.md** — visões de tabela e dashboard.

## Método dos 27 capítulos
3 atos × 9 capítulos. Cada `Cap NN` já vem com o seu *beat* anotado dentro,
no callout `[!summary]`. É um guia — mude livremente; a estrutura permanece.

## Convenções de nomes
- Capítulos: `Cap 01` … `Cap 27` (maiúscula, espaço, dois dígitos — sem underline).
- Numeração dos capítulos é **contínua** entre os atos (Ato 1 = 01–09, Ato 2 = 10–18, Ato 3 = 19–27).
