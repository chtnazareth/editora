# Escopo `oficina`

Cinco estágios, para quando o objetivo é **treinar**, não publicar: escrever uma cena solta, testar uma voz, experimentar uma abertura.

## O que roda

`convencoes-prosa` → `outline-cena` → `rascunho` → `passe-linha` → `retrospectiva`

## Por que `convencoes-prosa` fica

Porque o exercício sem registro declarado não ensina nada: você não sabe contra o que está medindo o resultado. Declarar a voz alvo antes é metade do exercício.

## Por que `retrospectiva` fica

É o único produto durável de uma oficina. A cena vai para a gaveta; a regra aprendida vai para `memoria/autor.md` e vale para todos os livros seguintes.
