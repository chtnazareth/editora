# Custo de regra

## O princípio

**Regra sem custo não é regra — é conveniência de enredo.** Se usar magia, tecnologia ou
poder não tira nada de ninguém, o mundo não tem física; tem desejo.

O custo é o que transforma capacidade em decisão. Sem ele, toda cena de perigo se
resolve pelo mesmo caminho, e o leitor para de temer.

## Os quatro campos

Para cada regra, a bíblia declara:

1. **O que faz** — precisão suficiente para o leitor prever o resultado
2. **O que custa, e a quem** — o custo precisa cair sobre alguém com nome. Custo difuso
   ("enfraquece o mundo") não pesa em cena nenhuma
3. **O limite** — o que ela não faz, e o que acontece quando alguém força
4. **Quem já quebrou** — o precedente que as pessoas citam com medo

O quarto é o mais produtivo na página: a regra vira concreta quando existe uma história
que todo mundo conhece.

## O teste da conveniência

Se o sistema resolve um problema exatamente no capítulo em que o problema aparece, ele
não é sistema — é saída de emergência.

Verificação: liste cada uso da regra no plano de capítulos. Quantos resolvem uma
dificuldade? Quantos **criam** uma? Se a proporção pende muito para o primeiro, o
sistema está servindo ao enredo em vez de pressioná-lo.

## O limite é onde mora a tensão

O que o sistema **não** faz vale mais, dramaticamente, que o que ele faz. Um mundo em
que tudo é possível não tem escolha difícil.

Declare os limites com a mesma precisão dos poderes — e prefira limites que criem
dilema, não apenas obstáculo.

## Como a regra chega ao leitor

Nunca por explicação, sempre por atrito: alguém tromba nela, alguém paga o preço, alguém
se recusa a usar. **Um gesto vale um parágrafo de exposição.**

Para cada regra importante, registre na bíblia **o gesto que a revela** — é o que o
prosista vai usar em vez de explicar.

## Podar

Construa só o que a página vai cobrar. Sistema com dezessete categorias das quais três
aparecem é dívida: você vai se sentir obrigado a usar as outras catorze, e cada uso é um
capítulo que a história não pediu.
